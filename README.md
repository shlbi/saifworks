# Saifworks

Personal portfolio of Saif Alshalabi — [saifworks.vercel.app](https://saifworks.vercel.app).

## About

Interactive single-page portfolio featuring a project workshop, 3D canvas artwork, project explorer, gallery filters, keyboard command menu, creative playground, responsive layout, and reduced-motion controls.

### Featured projects

- **REPOT** — [getrepot.com](https://getrepot.com) — feature transfer between repositories.
- **Parallax** — intelligence interface (in development; demo in portfolio is illustrative).
- **Ghost Director** — AI-assisted film creation concept.
- **Wanneesh** — truck services platform concept for Jordan.

## Run locally

No build is needed. Serve this directory with any local HTTP server, for example:

```sh
python -m http.server 8000
```

Then visit [localhost:8000](http://localhost:8000).

## Deployment

Connected to Vercel through GitHub. The root domain `saifworks.com` should point to the portfolio's Vercel project; other apps are best deployed independently and attached via subdomains such as `parallax.saifworks.com`. The portfolio can link to those apps once deployed.

## Notes

The in-page demos are simulations, not production product integrations. Live project links should only be added after launch. Interactive artwork is designed to pause on reduced-motion preferences.
